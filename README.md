# EMB Docs

Offline documentatie- en presentatie-app voor Entrepose Mills Benelux (iPad).

- Online via GitHub Pages: open de link in Safari op de iPad en kies Deel → Zet op beginscherm.
- Documenten worden enkel lokaal op het toestel bewaard, nooit in deze repository.
- Nieuwe versie: vervang `index.html` en verhoog de cacheversie in `sw.js`.
